Reporter Proto quick tour
This board is intentionally simple: add blocks from Templates, spawn dashboards from the toolbar, and use groups to collect cards across dashboards without mixing canvases.
1
Add blocks
Use Add template block in the top right or open Templates from the sidebar.
2
Spawn dashboards
Use the + button in the dashboard tab strip to create another isolated canvas.
3
Group across boards
Create a group, turn on Group mode, then tick cards from any dashboard and open the collected view.
